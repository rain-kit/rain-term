# 手工测试清单

发布前在 Windows 11、macOS、Ubuntu 上各走一遍。测试用的 SSH 服务器可以用集成测试的容器：

```bash
docker compose -f src-tauri/tests/docker/compose.yaml up -d --build --wait
docker compose -f src-tauri/tests/docker/compose.yaml port target 22    # 目标机端口
docker compose -f src-tauri/tests/docker/compose.yaml port bastion 22   # 跳板机端口
```

用户 `tester`，密码 `pa55`；经跳板机连接时目标机地址填 `target`、端口 `22`。测完用 `down` 删除容器。

不想动自己的连接时，设置环境变量 `RAIN_DIAL_DATA_DIR` 指向一个空目录再启动。

结果填 ✓（通过）、✗（失败，写明问题）、—（不适用）或待测。

Windows 一列的 ✓ 是开发中各任务在 Windows 11 上用开发版或 release 构建实测的结果（2026-11-17 至 11-18），还没用安装包测过；待测的项目和 macOS、Ubuntu 两列，拿到 CI 打出的安装包后补测。
